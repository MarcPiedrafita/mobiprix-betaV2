# Mobiprix Outlet

Web d'outlet de Mobiprix: peces úniques de mobiliari d'exposició amb tares,
que es reserven i es recullen a la botiga. Sense pagament en línia.

Astro estàtic sobre Cloudflare Pages. Català per defecte, castellà a `/es`.

> **Demo de presentació.** El contingut (peces, preus i tares) és fictici i no
> hi ha cap servei extern connectat. No és la versió de producció.

El desenvolupament va per branques; consulta les pull requests obertes.
